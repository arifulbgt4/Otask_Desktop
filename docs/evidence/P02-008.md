# Task Evidence: P02-008

- Task: implement key rotation and device revocation so old keys/grants stop
  working after revocation.
- Added security-definer, service-role-only SQL functions:
  - `rotate_device_key` verifies the current active key/version, marks it
    rotated, inserts the higher-version Ed25519 key atomically, updates the
    device version, and writes a redacted audit event.
  - `revoke_device` marks the device revoked, revokes all device keys and
    session grants, consumes outstanding pairing challenges, and records the
    reason in the append-only audit ledger.
- Added authenticated Edge Functions `rotate-device-key` and `revoke-device`.
  Rotation requires a current-key Ed25519 signature over the new key/version;
  revocation requires same-user ownership. Both reject revoked/foreign devices
  and never expose service-role credentials.
- pgTAP checks service-only function privileges, security-definer boundaries,
  protected audit/grant tables, and the existing runtime/validation fixtures
  cover invalid rotation/revocation input.
